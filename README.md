# Mayur Kishore Kumar — Machine Learning Engineer

Welcome to my personal portfolio website! This is a retro-styled, interactive portfolio showcasing my work as a Machine Learning Engineer specializing in production AI/ML systems, generative AI, RAG systems, agents, MCPs, and AI developer tooling.

🌐 **Live Site**: [mayurkishorekumar.github.io](https://mayurkishorekumar.github.io/)

## 🎮 About This Project

This portfolio is designed as an immersive, retro game-inspired experience featuring:

- **Game-Themed UI**: Classic Nintendo-inspired design with a "world map" navigation system
- **Interactive Elements**: Coin collection mechanics and responsive gameplay-style animations
- **Responsive Design**: Fully mobile-optimized with dedicated mobile styling
- **Modern Web Standards**: Clean HTML5, vanilla JavaScript, and CSS3 implementation

## 🚀 Getting Started

### Local Development

1. Clone the repository:
   ```bash
   git clone https://github.com/MayurKishoreKumar/MayurKishoreKumar.github.io.git
   cd MayurKishoreKumar.github.io
   ```

2. Serve locally (using Python):
   ```bash
   # Python 3
   python -m http.server 8000
   
   # Python 2
   python -m SimpleHTTPServer 8000
   ```

3. Open your browser to `http://localhost:8000`

### GitHub Pages

This repository is configured as a GitHub Pages site. Changes pushed to the `main` branch are automatically deployed to `https://mayurkishorekumar.github.io/`

## 📱 Responsive Design

The site is fully responsive with breakpoints for:
- **Desktop**: Full experience with all animations and interactions
- **Tablet & Mobile**: Optimized layout via `mobile.css` media queries (max-width: 600px)

Test responsiveness by resizing your browser or using DevTools device emulation.

## 🎨 Customization

### Modifying Content

- **HTML**: Edit `index.html` to update portfolio content
- **Styles**: Primary styles in `style.css`, mobile-specific in `mobile.css`
- **Interactivity**: Update `script.js` for dynamic behavior

### Changing Colors & Fonts

- Font imports and color scheme defined in `style.css`
- Theme overrides in `theme-fixes.css`
